# 开机动画适配 · TrimForge

把带 trim.txt 的开机动画拖进来，自动还原成 ColorOS 能认的完整版本。

纯前端网页工具，所有处理都在浏览器本地完成，文件不会上传到任何服务器。

## 功能

- 还原 trim.txt 裁剪帧，输出全尺寸画面
- desc.txt 转成 ColorOS 的 g 格式
- 自定义画面尺寸、背景色（自动检测 / HSV 取色器 / 手动输入）
- 透明像素填充背景色，防止花屏
- 按 desc 顺序整段预览，也可以单独看某个 part
- 存储模式（零压缩）打包，直接替换进 /system/media 就能用
- 深浅色主题，右上角圆形展开切换

## 使用方法

1. 打开页面（本地打开 index.html，或部署到 GitHub Pages）
2. 把 bootanimation.zip 拖进去（或点击选择）
3. 按需调整参数，点「开始处理」
4. 预览确认后点「下载新包」
